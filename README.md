# SMART STUDY PLANNER
เว็บพร้อมนำขึ้น GitHub Pages

ไฟล์หลัก: index.html, style.css, script.js

วิธีเผยแพร่:
1. สร้าง Repository บน GitHub เช่น smart-study-planner
2. อัปโหลดไฟล์ 3 ไฟล์หลัก
3. Settings > Pages
4. Source: Deploy from a branch
5. Branch: main และ / (root)
6. Save แล้วเปิดลิงก์ที่ GitHub สร้างให้

หมายเหตุ: ข้อมูลแผนการอ่านบันทึกด้วย LocalStorage จึงอยู่ในเบราว์เซอร์ของเครื่องนั้น ไม่ใช่ฐานข้อมูลออนไลน์ส่วนกลาง
